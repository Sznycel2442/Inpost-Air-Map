# InPost Air Map

[Otwórz mapę paczkomatów i pomiarów](https://sznycel2442.github.io/Inpost-Air-Map/).

Projekt pokazuje paczkomaty InPost na mapie OpenStreetMap oraz ostatnie potwierdzone pomiary jakości powietrza. Po kliknięciu punktu wyświetla wszystkie dostępne wartości czujników, czas odczytu i status źródła. Mapa rozróżnia punkty z pomiarami, punkty bez potwierdzonych danych oraz błędy pobrania.

Strona działa na GitHub Pages i korzysta z zapisanej migawki danych. Pomiary pochodzą z publicznych stron InPost; endpoint pomiarowy nie jest oficjalnie udokumentowany i może się zmienić. Projekt nie jest powiązany z InPost.
